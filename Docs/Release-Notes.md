# 版本记录

## v0.1.10

移除快捷指令朗读前的文本确认，校验输入后直接加载并播放。保留正文及关闭 / 重复播放弹层；现有快捷指令动作身份和 text 参数不变，无需重新导入。

## v0.1.9

首次公开源码基线，包含之前迭代完成的分享朗读、复制确认快捷指令、本地音频缓存、音量增强、500 条历史、收藏置顶及等高滑动操作。

音频会话在构造和准备播放器之前配置为 playback / spokenAudio 并启用，修复先 prepareToPlay 后配置会话的顺序缺陷。三个相关测试通过；旧顺序对照能触发回归断言。用户已确认 0.1.9 手机测试通过。

快捷指令播放卡片仅包含正文和关闭 / 重复播放。复用现有音频，不再次调用 Cartesia；保留现有工作流的动作身份与参数。

本记录从公开基线开始，不伪造此前版本的 Git 提交历史。针对个人签名配置的包、设备信息、私有密钥和调试记录不随公开仓库发布。
